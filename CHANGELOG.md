# Changelog

## 0.1.0 (2026-09-05)

- Initial Ruby client for Checkify's address, business, identity, communication, account, and bulk APIs.
- Support JSON and CSV bulk submissions.
- Offline VCR playback, opt-in production recording, and simulated bulk tests.
- Ruby 3.3 or later; packaged files exclude local credentials, recordings, and development files.
- Per-instance client with endpoint groups, a 30-second default timeout, and configurable redirect handling.
